♻️ Trabajo guardado
La app guarda automáticamente los datos en este teléfono. Si Chrome recarga, intentará recuperar los datos. Para evitar pérdidas, descarga una copia del sorteo regularmente, especialmente antes de salir de Chrome.
El guardado automático permanece dentro de este teléfono: no aparece como archivo en Descargas. «Recuperar último guardado» busca ese estado local. «Importar archivo» requiere un JSON descargado anteriormente. Las copias contienen datos personales y bancarios: protégelas.
